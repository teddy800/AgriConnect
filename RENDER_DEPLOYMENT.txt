🚀 AGRICONNECT RENDER DEPLOYMENT GUIDE
========================================

STEP 1: PREPARE REPOSITORY
---------------------------
1. Make sure all changes are committed to Git
2. Push to GitHub:
   
   git add .
   git commit -m "Production ready - Render deployment"
   git push origin main

STEP 2: CREATE RENDER ACCOUNT
------------------------------
1. Go to https://render.com
2. Sign up with GitHub account (recommended)
3. Authorize Render to access your repositories

STEP 3: DEPLOY USING BLUEPRINT
-------------------------------
1. Click "New +" → "Blueprint"
2. Connect your AgriConnect repository
3. Render will detect render.yaml automatically
4. Click "Apply" to create all services:
   ✅ Backend API
   ✅ Frontend Static Site
   ✅ PostgreSQL Database

STEP 4: CONFIGURE ENVIRONMENT VARIABLES
----------------------------------------
After deployment starts, update these in Render Dashboard:

BACKEND SERVICE:
1. Go to agriconnect-backend → Environment
2. Add/Update:
   - CORS_ORIGIN = https://agriconnect-frontend.onrender.com
   - JWT_SECRET = (auto-generated, verify it's 64+ chars)
   - OPENWEATHER_API_KEY = your_api_key_here (optional)

FRONTEND SERVICE:
1. Go to agriconnect-frontend → Environment
2. Update:
   - VITE_API_URL = https://agriconnect-backend.onrender.com/api
   
3. Click "Manual Deploy" → "Clear build cache & deploy"

STEP 5: INITIALIZE DATABASE
----------------------------
Once backend is deployed:

1. Go to agriconnect-backend → Shell
2. Run database setup:
   
   cd backend
   psql $DATABASE_URL -f db/schema.sql
   psql $DATABASE_URL -f db/seed2_updated.sql
   psql $DATABASE_URL -f db/admin_setup.sql

3. Or connect via Render's PostgreSQL client

STEP 6: UPDATE ADMIN PASSWORD
------------------------------
1. In Render Shell (backend service):
   
   cd backend
   node -e "const bcrypt = require('bcryptjs'); console.log(bcrypt.hashSync('YOUR_NEW_PASSWORD', 10));"

2. Copy the hash output

3. In PostgreSQL:
   
   psql $DATABASE_URL
   UPDATE users SET password_hash = 'PASTE_HASH_HERE' WHERE role = 'admin';
   \q

STEP 7: VERIFY DEPLOYMENT
--------------------------
1. Backend Health:
   https://agriconnect-backend.onrender.com/api/health
   Should return: {"ok":true,"status":"healthy"}

2. Frontend:
   https://agriconnect-frontend.onrender.com
   Should load the application

3. Test Login:
   - Admin Phone: 0911111111
   - Admin Email: admin@agriconnect.com
   - Password: (your new password)

STEP 8: CUSTOM DOMAIN (OPTIONAL)
---------------------------------
1. Buy domain (e.g., agriconnect.et)
2. In Render Dashboard:
   - Frontend service → Settings → Custom Domain
   - Add: www.agriconnect.et
3. Update DNS:
   - CNAME: www → agriconnect-frontend.onrender.com
4. Update backend CORS_ORIGIN to: https://www.agriconnect.et

TROUBLESHOOTING
---------------
❌ Build Failed:
   - Check build logs in Render dashboard
   - Verify package.json has all dependencies
   - Try "Clear build cache & deploy"

❌ Database Connection Error:
   - Verify DATABASE_URL is set correctly
   - Check DB credentials in environment variables
   - Ensure database is running (check status)

❌ CORS Error:
   - Update CORS_ORIGIN in backend to match frontend URL
   - Redeploy backend after changing

❌ 404 on Frontend Routes:
   - Routes configured in render.yaml (rewrite to /index.html)
   - Should work automatically

❌ WebSocket Not Working:
   - Render supports WebSocket on paid plans
   - Free tier has limitations
   - Upgrade for full WebSocket support

MONITORING
----------
1. Render Dashboard: Monitor CPU, memory, requests
2. Logs: View real-time logs in each service
3. Metrics: Check response times and errors
4. Alerts: Configure in Render settings

BACKUP STRATEGY
---------------
1. Database: Render provides daily backups (Starter plan+)
2. Manual: Use Render Shell to export:
   pg_dump $DATABASE_URL > backup.sql
